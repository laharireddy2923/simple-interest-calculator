# simple-interest-calculator

Project Description
The Simple Interest Calculator is a simple application used to calculate interest based on the principal amount, rate of interest, and time period.

Formula
Simple Interest = (Principal × Rate × Time) / 100

Technologies Used
Java

Features
Takes principal amount as input.
Takes rate of interest as input.
Takes time period as input.
Calculates simple interest.
Displays the final amount.

Conclusion
This project helps users calculate simple interest easily and quickly.
